# UI evidence

Changed UI needs real before and after screenshots in the PR description. Match the viewport, route, data, and interaction state across each pair. Capture one pair per materially different changed state.

- **Before:** capture on the original revision before editing. If you missed it, capture it in a separate host-managed workspace on the original revision and leave the current edits in place.
- **After:** capture after verification.

Embed them as uploaded attachments or repository-permitted URLs that PR readers can open, and confirm both images render.

If browser access, a running UI, representative data, or image upload is unavailable, report the blocker and request the capability. The screenshot gate stays open until real images render in the PR.
